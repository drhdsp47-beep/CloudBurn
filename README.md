# 🔥 CloudBurn: Zero-Cost AI Router

Stop paying cloud and AI bills! **CloudBurn** is an open-source, ultra-fast API gateway designed to eliminate your AI spending entirely. It automatically intercepts API requests and routes them to **100% free, local, open-source models** running on your own infrastructure, bringing your AI API costs down to exactly **$0.00**.

## 🚀 Features
* **True Zero-Cost Routing:** Instantly redirects expensive commercial API calls to free, self-hosted local models.
* **Privacy-First & Offline:** Since all models run locally, no data ever leaves your servers. Zero leakage, zero compliance issues.
* **Plug & Play:** Drop-in replacement for standard AI cloud endpoints with zero friction.

## 🛠️ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com
cd cloudburn-router
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Zero-Cost Router
```bash
python app.py
```
